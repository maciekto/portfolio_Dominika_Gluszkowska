# Dominika gluszkowska portfolio project (after migrate to VUE)

# How to start on newer nodejs


```bash
# Uninstal
npm uninstall node-sass

# Install
npm install -D sass sass-loader@10
npm install

# Run
export NODE_OPTIONS=--openssl-legacy-provider
npm run serve

```
